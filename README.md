# PDF-формы для преподавателей и учёных

Проект для разработки PDF-форм по сбору информации от преподавателей и учёных. Организация подпроектов и правила работы описаны в [структуре проекта](doc/project-structure.md).

## Каталог форм

- [prepod_vnok_info](forms/prepod_vnok_info/docs/README.md) — сведения о научной работе преподавателя со студентами (курсантами). Версии: 2.0 — статичная форма на одного студента (рекомендуется), 1.0 — динамическая XFA.
