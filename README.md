# PDF-формы для преподавателей и учёных

Проект для разработки PDF-форм по сбору информации от преподавателей и учёных. Организация подпроектов и правила работы описаны в [структуре проекта](doc/project-structure.md).

## Каталог форм

- [prepod_vnok_info](forms/prepod_vnok_info/docs/README.md) — форма для сбора информации от конкретного преподавателя, который ведёт научную работу со студентами.
