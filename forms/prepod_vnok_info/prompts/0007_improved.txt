Подготовь набор из 10 заполненных PDF-форм prepod_vnok_info версии 2.0 «один файл — один студент» для тестирования программы, которая обрабатывает эти формы.

Работай в подпроекте forms/prepod_vnok_info/. Перед началом изучи docs/static-form.md, docs/data-schema-v2.json, docs/example-data-v2.json и исходники src/static/ (build_static_form.py, acroform.py, prepare_copy.py, extract_static.py, test_static_form.py). Саму форму, схему данных и существующие скрипты не изменяй. XFA-версию 1.0 не используй.

1. Где и что создать

Создай папку forms/prepod_vnok_info/examples/ и положи в неё:
- 10 заполненных PDF: 01-....pdf … 10-....pdf. После номера — короткое латинское описание случая, например 03-no-middle-name.pdf;
- для каждого PDF — ожидаемый результат извлечения с тем же именем и расширением .json (JSON по схеме 2.0);
- README.md: таблица «файл — что проверяет — ожидаемый результат `extract_static.py --check` (код выхода, ошибки, предупреждения)» и команда для повторной генерации;
- скрипт генерации, например examples/generate_examples.py, который из исходных данных строит все PDF и JSON. Набор должен воспроизводиться одной командой.

Исходная форма — актуальный черновик output/drafts/prepod_vnok_info-v2.0-draft04.pdf. Каждую копию готовь через prepare_copy.py (функцию prepare_copy), чтобы у неё был ID анкеты. ID задавай явно и детерминированно (например student-example-01 … student-example-10), а не случайным UUID: иначе ожидаемые JSON будут меняться при каждой генерации. Значения полей записывай через acroform.set_values, чтобы внешний вид полей строился встроенным шрифтом Liberation Serif и текст был виден в любом просмотрщике. Существующие файлы не перезаписывай молча: скрипт либо очищает только свои файлы в examples/, либо требует флаг --force.

2. Содержание

Все тексты на русском языке, реалистичные для научной работы преподавателя со студентом (курсантом) вуза: разные кафедры, должности, курсы с 1 по 6, разные темы задач, статусы, расписания и портфолио. Не повторяй один и тот же шаблон с заменой имён.

Данные только вымышленные:
- ФИО не должны совпадать с известными людьми;
- email только в домене example.org / example.com / example.ru;
- телефоны заведомо несуществующие, в разных записях: «+7 (900) 000-00-01», «8 900 000 00 02», «+7-900-000-00-03».

3. Покрытие случаев

Набор должен проверять разные ветви обработки. Примерное распределение:

Корректные формы (--check: код 0, без ошибок):
1. Полностью заполненная форма: все поля, все 10 строк портфолио.
2. Минимально заполненная: только обязательные поля (фамилия, имя, шифр группы, телефон, email, задача) и дата; остальное пусто.
3. Без отчества (иностранный студент или курсант с двойной фамилией через дефис).
4. Длинные тексты: задача и ожидаемые результаты на много абзацев, расписание на 8+ строк — проверка многострочных полей и переводов строк.
5. Сложные символы: ё/Ё, ъ, кавычки «», тире —, №, знаки +, ведущие нули в шифре группы и телефоне; значения должны извлекаться без изменений.
6. Дата в формате ISO `ГГГГ-ММ-ДД`, как её сохраняет Firefox: в JSON ожидается `ДД.ММ.ГГГГ`.
7. Портфолио с пропусками: заполнены строки 1, 4 и 7 — проверка, что `achievements[].id` сохраняет номер строки (achievement-1, achievement-4, achievement-7).

Формы с ошибками и предупреждениями (для проверки диагностики):
8. Предупреждение: курс вне диапазона 1–6 (например «7» или «II»), ошибок нет, код 0.
9. Ошибки: неверный email и несуществующая дата (например 31.02.2026), код 2.
10. Ошибка: не заполнены обязательные поля (например телефон и задача), код 2.

Если какой-то случай при проверке ведёт себя не так, как описано в docs/static-form.md, не подгоняй ожидание под фактический результат: опиши расхождение в README.md и сообщи мне.

4. Проверка

- Прогони extract_static.py --check по каждому PDF и сравни результат с соответствующим .json побайтно (после канонической сериализации); код выхода и сообщения должны совпадать с таблицей в README.md.
- Добавь автоматический тест (в src/static/test_static_form.py или отдельный test в examples/), который выполняет эту сверку для всех 10 файлов.
- Убедись, что существующие тесты src/static/ проходят.
- Отрендери первую страницу 2–3 файлов в PNG (во временную папку, не в репозиторий) и проверь глазами, что текст в полях виден и не обрезан там, где не должен быть.
