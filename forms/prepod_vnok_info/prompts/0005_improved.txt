Внеси изменения в статичную PDF-форму prepod_vnok_info версии 2.0 «один файл — один студент» (AcroForm без XFA, JavaScript и кнопок).

Работай в подпроекте forms/prepod_vnok_info/. Перед началом изучи doc/project-structure.md, docs/static-form.md, doc/static-pdf-form-one-student.md и исходники src/static/. XFA-версию 1.0 (src/build_form.py, src/form.js, src/extract_data.py, черновики v1.0) не изменяй.

1. Новые поля

- Дата заполнения формы. Текстовое поле в формате ДД.ММ.ГГГГ: средств выбора даты без JavaScript нет. Значение не преобразовывать при сохранении. Корректность даты проверять при извлечении данных.
- Кафедра, на которой работает преподаватель. Поле размещается в блоке преподавателя.
- Номер курса студента (курсанта). Хранить как текст. При проверке допускать целое число от 1 до 6, иначе выдавать предупреждение.

Новые поля необязательны. Не делай их обязательными без отдельного требования.

2. Изменения существующих полей

- Заголовок формы: «Информация о студенте (курсанте)». Обнови его и в метаданных PDF (Title).
- Вместо одного поля «Полные ФИО» студента сделай три отдельных поля: «Фамилия», «Имя», «Отчество». Фамилия и имя обязательны. Отчество необязательно, так как может отсутствовать. ФИО преподавателя не разделяй.
- Расписание работы с преподавателем: удали 5 структурированных строк (режим работы, флажки дней недели, время начала и окончания, аудитория). Вместо них сделай одно многострочное поле «Расписание работы с преподавателем», в котором преподаватель свободно описывает режим работы, дни, время и место. Поле необязательно. Высота поля должна вмещать не менее 6–8 строк.
- Остальные поля сохрани без изменения смысла и обязательности: шифр группы, телефон, электронная почта, задача, ожидаемые результаты, статус, 10 строк портфолио, примечание, служебные поля, ID анкеты.

3. Шрифт

Используй Times New Roman или метрически совместимый с ним шрифт с полной кириллицей и лицензией, разрешающей встраивание и распространение вместе с исходниками. Times New Roman — проприетарный шрифт, его нельзя добавить в репозиторий. Поэтому по умолчанию используй Liberation Serif Regular (SIL OFL 1.1, метрики Times New Roman), а при необходимости и Liberation Serif Bold для подписей и заголовков. Положи файлы шрифтов и текст лицензии в src/static/fonts/. Сохрани принятые правила: шрифт полей встраивается в /AcroForm/DR полностью, без подмножества, с /ToUnicode. Удали из исходников шрифт Liberation Sans, если он больше нигде не используется.

4. Раскладка «метка слева, поле справа»

- Каждое поле располагается в строке сетки: метка в левой колонке шириной 30% ширины содержимого, поле в правой колонке шириной 70%. Ширина колонок одинакова во всей форме.
- Метку однострочного поля выравнивай по вертикальному центру поля, многострочного — по верхнему краю поля. Длинные метки переносятся внутри левой колонки и не заходят на поле. Если перенесённая метка выше поля, высота строки увеличивается.
- Звёздочка обязательного поля остаётся в метке.
- Заголовки разделов, вводная инструкция и примечания к разделам занимают всю ширину.
- Флажков в форме больше нет. Строки портфолио: номер достижения в левой колонке, поле в правой.
- Размер страницы A4. Поля не перекрываются и не выходят за поля страницы. Порядок Tab идёт сверху вниз, у каждого поля сохранена подсказка /TU, совпадающая с меткой.

5. Данные и совместимость

- Изменение структуры данных несовместимо со схемой 1.0. Введи схему данных 2.0 для статичной формы:
  - новые поля: дата заполнения, кафедра, курс;
  - ФИО студента: last_name, first_name, middle_name вместо full_name;
  - schedule: строка вместо списка записей.
  Опиши её в отдельном файле docs/data-schema-v2.json, а пример на вымышленных данных — в docs/example-data-v2.json. Схему 1.0 и её пример оставь для XFA-версии.
- Машинные имена новых полей формы (например, meta.date_filled, teacher.department, student.course, student.last_name, student.first_name, student.middle_name, student.schedule) должны быть стабильными. Опиши соответствие полей PDF и путей JSON.
- Значение meta.schema_version в форме — «2.0». Извлечение должно отклонять файлы v2.0-draft01 со схемой 1.0 понятным сообщением, а не выдавать неполные данные.
- Обнови extract_static.py, prepare_copy.py и проверку --check: обязательные поля (фамилия, имя, шифр группы, телефон, email, задача), формат email, формат и существование даты, номер курса.
