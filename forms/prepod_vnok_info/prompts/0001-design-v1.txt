Создай PDF-форму для сбора информации от конкретного преподавателя, который ведёт научную работу со студентами (курсантами)
В форме предусмотреть следующие поля для ввода:
ФИО преподавателя
Должность
У каждого преподавателя может быть один или несколько студентов (курсантов), по это причине необходимо предусмотреть интерактивно добавление в форме студентов (курсантов) с введением информации о каждом из необходимо
Должна быть предусмотрена возможность в форме управлением списками студентов (курсантов) - редактирование информации, удаление записей, добавление новых
В структуру информации о студенте (курсанте)неохходимо включить следующие поля:
*Полные ФИО 
*Шифр группы
*Телефон
*Электронная почта
*Большое поле где описана задача поставленная студенту (курсанту) преподавателем
Режимим работы с  преподавателем (расписание включающее режим работы, дни недели, время и аудиторию в которой студент будет работать)
Ожидаемые результаты
Текужий статус выполнения задания
Портфолио (список достижений студента (курсанта))
Примечание

Поля со звездочками являются обязательными
Предусмотреть сохранение формы и возможность ее редактирования после сохранения
Сохраненная форма в будущем может испоьльзоваться для автоматического извлечения информации из не в сторонних приложениях и api
