# Инструкция для преподавателя

Форма «Научная работа со студентами» — интерактивный PDF. Вы вносите сведения о себе и о каждом студенте (курсанте), с которым ведёте научную работу.

> **Статус: черновик.** Форма ещё не прошла приёмочную проверку в Acrobat/Reader и Edge ([чек-лист](acceptance-checklist.md)). До её прохождения не передавайте форму преподавателям для реального заполнения.

## 1. Чем открывать

| Программа | Подходит? |
| --- | --- |
| **Adobe Acrobat Reader** (бесплатный) или Adobe Acrobat, Windows или macOS | **Да, рекомендуется.** Скачать: <https://get.adobe.com/reader/> |
| Microsoft Edge (Windows, macOS) | Только если администратор настроил его по [инструкции](viewer-setup.md#microsoft-edge). Без настройки не работает. |
| Chrome, Firefox, Safari, Яндекс Браузер, «Предпросмотр» macOS, мобильные приложения, онлайн-просмотрщики | **Нет.** Кнопки добавления и удаления записей в них не работают, сохранённые данные могут потеряться. |

Если файл открылся в браузере, сохраните его на компьютер, затем щёлкните правой кнопкой мыши → «Открыть с помощью» → Adobe Acrobat Reader.

## 2. Как понять, что форма работает

Под заголовком формы есть строка состояния:

- **зелёная** «Сценарии формы работают: Acrobat …» — всё в порядке, можно заполнять;
- **красная** «Сценарии формы НЕ работают…» — кнопки работать не будут. Выполните шаги ниже;
- тёмная страница с текстом «Ваша программа не открыла интерактивную форму» — файл открыт в неподходящей программе (см. п. 1).

Если строка красная в Acrobat Reader:

1. Если вверху окна жёлтая панель «Защищённый режим» (Protected View), нажмите **«Включить все функции»** (Enable All Features).
2. Проверьте, что JavaScript включён: **Меню → Установки** (Ctrl+K, на macOS Cmd+K) → **JavaScript** → флажок **«Включить JavaScript Acrobat»**. Затем закройте и снова откройте файл.
3. Если не помогло, обратитесь к администратору: в организации JavaScript может быть отключён политикой.

## 3. Заполнение

1. Перед началом сохраните копию пустой формы под своим именем, например `Научная_работа_Иванов.pdf`.
2. Заполните **ФИО преподавателя** и **должность**.
3. Заполните карточку первого студента. Поля со **звёздочкой (*)** обязательны: полные ФИО, шифр группы, телефон, электронная почта, задача. Остальные поля можно оставить пустыми.
4. Телефон и шифр группы вводятся в любом виде: `+7 (900) 000-00-00`, `001-А`. Ведущие нули, «+» и буквы сохраняются.
5. **Расписание.** Нажмите «Добавить занятие» для каждого варианта времени и места: например, отдельно «Пн, Ср 15:00–17:00, ауд. 101» и «Пт 10:00–12:00, лаб. 3». Время вводится в формате `ЧЧ:ММ`.
6. **Портфолио.** Кнопка «Добавить достижение» создаёт отдельную запись для каждого достижения.
7. **Статус задания** — свободный текст: например, «в работе», «на проверке», «доклад принят на конференцию».
8. Чтобы добавить следующего студента, нажмите **«Добавить студента (курсанта)»**. Новая карточка появится в конце списка, введённые ранее данные сохранятся.
9. Длинные поля (задача, ожидаемые результаты, примечание) увеличиваются по мере ввода. При необходимости добавляются страницы.

## 4. Изменение и удаление

- Любое поле можно исправить в любой момент, в том числе после сохранения и повторного открытия.
- Кнопки «Удалить студента (курсанта)», «Удалить занятие», «Удалить достижение» удаляют только свою запись. Перед удалением появится вопрос. Ответ «Нет» оставляет запись без изменений.
- Удаление нельзя отменить после подтверждения. Если удалили по ошибке, закройте файл **без сохранения** и откройте последнюю сохранённую версию.

## 5. Проверка и сохранение

1. Нажмите **«Проверить заполнение»**. Форма сообщит о незаполненных обязательных полях, ошибках в адресе электронной почты и времени.
2. Сохраните файл: **Файл → Сохранить** или **Файл → Сохранить как…**. Незавершённую форму тоже можно сохранить и дозаполнить позже.
3. **Не используйте «Печать → Microsoft Print to PDF / Сохранить как PDF»** для сохранения: получится нередактируемая копия без данных для автоматической обработки.
4. Чтобы продолжить работу, откройте сохранённый файл в Acrobat Reader. Все карточки, расписания и достижения сохранятся. Их можно редактировать, добавлять и удалять.

## 6. Печать

Печатайте из Acrobat Reader: **Файл → Печать**. Кнопки и строка состояния на бумагу не выводятся. Если текст в поле очень длинный (больше страницы), перед печатью проверьте, что он виден целиком. Подробнее об этом ограничении — в [README](README.md#известные-ограничения).

## 7. Отправка

Отправьте сохранённый PDF-файл ответственному лицу тем способом, который указан в вашей организации. Не конвертируйте и не «оптимизируйте» файл сторонними сервисами: это может удалить данные формы.
