| Проверка | Фактический результат | Предел проверки |
| --- | --- | --- |
| Новая форма | В PDF сохранены пустой преподаватель и один студент с ID | Это проверка данных и упаковки PDF |
| Три студента, удаление средней записи, добавление новой | Остальные значения и ID сохраняются, удалённая запись отсутствует | XFA API заменён тестовой моделью в JS; запись PDF проверена отдельно |
| Несколько занятий и достижений | Пример JSON проходит PDF → извлечение без изменений | Не проверено добавление кнопками в совместимом просмотрщике |
| Обязательность полей и email | Только пять обязательных полей; пустой преподаватель допустим; ошибочный email выявляется | Исполнен исходный JavaScript в Node.js, не в XFA-движке |

| Последняя ревизия PDF | Извлекаются изменения из инкрементального сохранения, а не старые значения | Новая ревизия записана pypdf, не пользовательским сохранением |

Тестовые данные вымышленные. Проверка извлечения последней ревизии не доказывает, что конкретный просмотрщик правильно синхронизирует форму и `datasets`.

## Фактическая проверка просмотрщика (draft03)

Среда: Linux, Firefox **157.0.1**, PDF.js **6.3.335**, отдельный временный профиль, headless-режим. Проверка выполнялась через WebDriver BiDi: открытие локального PDF, чтение полей страницы, нажатие кнопки и снимок экрана.

- `draft01` и `draft02` не загружались из-за ресурсов шрифтов XFA. В текущем сборщике добавлены `/AcroForm/DR` и `FontFamily`/`FontWeight` у встроенного шрифта.
- `draft03` загружается и показывает две страницы, пустой блок преподавателя и одну карточку студента. Кириллические подписи читаемы на проверенном снимке первой страницы.
- На страницах найдено 10 видимых полей ввода. После нажатия «Добавить студента (курсанта)» число осталось 10, новая карточка не появилась. Этот сценарий **не пройден**.
- В журнале есть предупреждение PDF.js `XFA-editing is not implemented`, а также сообщения о подстановке Arial и отказе загрузить встроенное подмножество DejaVu Sans. Полный набор символов и метрики печати не подтверждены.
- Поэтому Firefox этой версии нельзя рекомендовать для данного задания. Присутствие кнопок на экране не означает выполнение их сценариев.

Acrobat/Reader на Windows/macOS и Edge с политикой XFA в доступной среде отсутствуют. Проверок в них не было. Успешно проверенного просмотрщика для полного цикла заполнения сейчас нет.
