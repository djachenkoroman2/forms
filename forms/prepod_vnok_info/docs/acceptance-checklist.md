# Чек-лист приёмки в Acrobat/Reader и Edge

Проверяемый файл: [prepod_vnok_info-v1.0-draft04.pdf](../output/drafts/prepod_vnok_info-v1.0-draft04.pdf). Используйте только вымышленные данные. Каждую среду проверяйте на **копии** пустого PDF.

Форма считается готовой к выпуску v1.0 в среде, где пройдены все пункты. Обязательна хотя бы одна основная среда: Acrobat Reader на Windows или macOS. Для Edge результат записывается отдельно. Непройденный пункт оставляет среду в статусе «не поддерживается». Результаты передайте разработчику или внесите в [протокол проверок](verification.md) с указанием даты и проверяющего.

## Извлечение данных для пункта 11

На компьютере разработчика из папки `forms/prepod_vnok_info/`:

```bash
.venv/bin/python src/extract_data.py /путь/сохранённая-копия.pdf --output /путь/результат.json
```

Сравните `students[].id` из файлов после пп. 9 и 10. Идентификаторы оставшихся студентов должны совпадать.

## Что делать при ошибках

- Красная строка состояния — проверить JavaScript и защищённый режим ([настройка](viewer-setup.md)), повторить.
- Кнопка не реагирует при зелёной строке, данные пропадают после сохранения, наложение полей — сделать снимок экрана, записать версию программы и номер пункта, приложить сохранённый PDF.
